# Burken Restaurant

เว็บไซต์สั่งอาหาร พร้อมระบบลูกค้า พนักงาน ผู้ดูแล และไรเดอร์ ใช้ Next.js, React, Payload CMS และ SQLite

## เริ่มใช้งานบนเครื่องนี้

- ดับเบิลคลิก `start-production.cmd` เพื่อเปิดเว็บรุ่น production
- ดับเบิลคลิก `start-local.cmd` เพื่อเปิดโหมดพัฒนา
- ดู URL ที่แสดงในหน้าต่างเซิร์ฟเวอร์ โดยระบบเลือกพอร์ตว่างระหว่าง 3000–3010

คู่มือติดตั้งและบัญชีตัวอย่าง: [คู่มือใช้งานบนเครื่อง](docs/README-LOCAL.md)

วิธีใช้ออเดอร์ พิกัดจัดส่ง และไรเดอร์: [คู่มือจัดส่ง](docs/DELIVERY-AND-RIDER.md)

## โครงสร้างโฟลเดอร์

| ตำแหน่ง | เนื้อหา |
| --- | --- |
| `src/app/` | หน้าเว็บ เส้นทาง API และหน้า Payload Admin |
| `src/components/` | คอมโพเนนต์หน้าร้านและแดชบอร์ด |
| `src/collections/` | โครงสร้างข้อมูลและสิทธิ์ของ Payload |
| `src/lib/`, `src/access/` | ฟังก์ชันกลางและการตรวจสิทธิ์ |
| `docs/` | คู่มือติดตั้งและใช้งาน |
| `scripts/run.mjs`, `scripts/setup.mjs` | คำสั่งเปิดเว็บและเตรียมเครื่อง |
| `scripts/maintenance/` | สคริปต์ดูแล schema และอัปเกรดข้อมูล |
| `data/` | ฐานข้อมูล รูปยืนยันการจัดส่ง และไฟล์สำรอง |
| `media/` | รูปภาพที่อัปโหลด |
| `.cache/`, `.next/` | แคช TypeScript และผลลัพธ์ build |
| `.local/` | ข้อมูลส่วนตัวสำหรับการพัฒนาบนเครื่อง |
| `.figma/` | ไฟล์เดิมที่รองรับ Figma Make |

ไฟล์ตั้งค่า เช่น `package.json`, `next.config.ts`, `tsconfig.json` และ `.env` อยู่ที่รากโปรเจกต์เพื่อให้เครื่องมือค้นพบตามปกติ `src/payload-types.ts` และ `next-env.d.ts` เป็นไฟล์ที่เครื่องมือสร้างให้

ควรสำรอง `data/burken.db`, `media/` และ `.env` ไว้ด้วยกัน ห้ามเผยแพร่ `.env` หรือข้อมูลใน `.local/`
